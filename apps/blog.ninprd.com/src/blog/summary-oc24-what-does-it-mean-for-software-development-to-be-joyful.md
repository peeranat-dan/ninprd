วันนี้มาแบบสรุป Topic ที่เนื้อหาสั้นแต่ได้ใจสุด ๆ ของพี่แชมป์แห่ง ODDS| จากงาน ODDS| CONF 2024 ครับ เรื่องมันมีอยู่ว่าปกติแล้วชาว ODDS| จะเชื่อว่าการทำ Software ต้องสนุกครับ พี่แชมป์บอกว่าคนข้างนอก ODDS| อาจจะไม่รู้ หรือไม่เข้าใจว่าทำไมการทำ Software ต้องสนุก พี่แชมป์เลยมาขยายเล่าให้ฟังครับ รอบนี้นิลลองมาสรุปเป็น Bullet ดูครับ

1. สิ่งที่ชาว ODDS| เชื่อมาเสมอคือ “การทำ Software ต้องสนุก”
2. คำว่าสนุกของแต่ละคนไม่เหมือนกัน บางคนสนุกอาจจะหมายถึงได้ Challenge บางคนอาจจะหมายถึงการได้ชนะอะไรซักอย่าง หรือบางคนอาจจะรู้สึกเหมือนได้เปลี่ยนโลก
3. คำว่าเหนื่อยกับสนุกไม่เหมือนกัน บางครั้งเราทำงานหนักเราอาจจะรู้สึกเหนื่อย แต่ถ้ามันยังสนุกอยู่ = การทำ Software เรายังสนุกอยู่
4. ทำไมการทำ Software ต้องสนุก เพราะถ้าไม่สนุก เราก็จะนั่งหมดใจในออฟฟิศรอให้เวลาผ่านไปเรื่อย ๆ
5. คนที่เป็น Lead ต้องสามารถซื้อ Trust ของทีมให้ได้ เพื่อให้ทีมกล้าพูดว่าตัวเองยังสนุกกับงานอยู่หรือเปล่า
6. ถ้าคนในทีมไม่สนุกแล้ว สำหรับ Lead แล้วก็ต้องหาวิธีแหละ ถ้ายังอยากให้คนในทีมสนุกอยู่
7. ถ้างานมันสนุกแล้ว ชิ้นงานที่ออกมามันจะออกมาไม่แย่ อาจจะไม่ได้ดีเลิศ แต่ก็สามารถผ่านอุปสรรคที่เข้ามาได้ก่อน
8. พี่แชมป์ลองไปถามชาว ODDS| เรื่องของความสนุกของการทำ Software บางคนก็ตอบว่าการได้รับงานยาก ๆ และผ่านมันได้เป็นเรื่องสนุก บางคนก็ตอบว่าการได้ส่งของที่ดีให้ User เป็นเรื่องสนุก สรุปก็คือความสนุกของแต่ละคนไม่เหมือนกัน (เหมือนข้อ 2 นั่นเอง 5555)
